## Overview

The Raw Materials module is **new** — there is no existing frontend screen for it. It covers two sub-modules:

| Sub-module | Base Path | Description |
|---|---|---|
| Raw Materials | `/raw-materials` | Master catalogue of raw materials |
| Raw Material Batches | `/raw-material-batches` | Inventory batches received from GRNs |

**Raw Materials** is the master catalogue — it holds the definition of each material (name, code, UOM, stock levels).  
**Raw Material Batches** tracks individual lots received via Goods Received Notes (GRNs), with full FIFO/FEFO allocation and consumption tracking.

---

## Permissions

| Permission Key | What it guards |
|---|---|
| `raw-materials.create` | Create a raw material |
| `raw-materials.read` | List / view raw materials |
| `raw-materials.update` | Update, toggle active status |
| `raw-materials.delete` | Soft-delete a raw material |
| `stock.create` | Create batches from GRN |
| `stock.read` | List / view batches, FIFO allocation, consumption history |
| `stock.update` | Consume from batch, update batch status/notes |

## Enums & Constants

### `RawMaterialBatchStatus`

```
ACTIVE    — Batch is available; no consumption has happened yet
PARTIAL   — Some quantity has been consumed; stock remains
CONSUMED  — Entire batch quantity has been consumed
REJECTED  — Batch was rejected during quality inspection
```

### Batch Number Format

Auto-generated by the backend. Pattern: `RM-YYYYMM-XXXX`  
Example: `RM-202606-0001`

## Raw Materials API

### 1. Create Raw Material

```
POST /raw-materials
Permission: raw-materials.create
```

#### Request Body

```json
{
  "name": "Cotton Yarn",
  "code": "CTN-YARN",
  "description": "High-quality cotton yarn used in fabric production",
  "uomId": "8e000b71-e94d-497a-9247-eb170a41e826",
  "currentStock": 0,
  "reorderLevel": 50,
  "lastPurchasePrice": 150.00,
  "isActive": true
}
```

| Field | Type | Required | Notes |
|---|---|---|---|
| `name` | `string` | Yes | Display name of the material |
| `code` | `string` | Yes | 2–12 chars, uppercase alphanumeric + hyphens only. Backend auto-formats: lowercased input is uppercased, spaces become `-`, special chars stripped. E.g. `"sunflower oil"` → `"SUNFLOWER-OIL"` |
| `description` | `string` | No | Free-text description |
| `uomId` | `uuid` | Yes | Unit of Measurement ID (from UOM master) |
| `currentStock` | `number` | No | Default: `0`. Must be ≥ 0 |
| `reorderLevel` | `number` | No | Default: `0`. Triggers reorder alert when stock falls below this |
| `lastPurchasePrice` | `number` | No | Default: `0`. Per UOM unit. Must be ≥ 0 |
| `isActive` | `boolean` | No | Default: `true` |

#### Response `201 Created`

```json
{
  "id": "b3f9c1a2-4e2d-4a1b-9c3e-1a2b3c4d5e6f",
  "name": "Cotton Yarn",
  "code": "CTN-YARN",
  "description": "High-quality cotton yarn used in fabric production",
  "uomId": "8e000b71-e94d-497a-9247-eb170a41e826",
  "currentStock": 0,
  "reorderLevel": 50,
  "lastPurchasePrice": "150.00",
  "isActive": true,
  "deletedAt": null,
  "createdById": "user-uuid",
  "updatedById": null,
  "createdAt": "2026-06-04T10:00:00.000Z",
  "updatedAt": "2026-06-04T10:00:00.000Z",
  "uom": {
    "id": "8e000b71-e94d-497a-9247-eb170a41e826",
    "name": "Kilogram",
    "symbol": "kg"
  }
}
```

> **Note**: `lastPurchasePrice` is a `Decimal` — returned as a string in JSON. Parse it with `parseFloat()` or a Decimal library on the frontend.

```
Permission: raw-materials.update
```

#### Path Parameter

| Param | Type | Notes |
|---|---|---|
| `rawMaterialId` | `uuid` | ID of the raw material to update |

#### Request Body

All fields are optional — send only what you want to change.

```json
{
  "name": "Cotton Yarn Premium",
  "description": "Updated description",
  "reorderLevel": 100,
  "lastPurchasePrice": 175.50

```

#### Response `200 OK`

Full updated raw material object (same shape as create response).

### 6. Delete Raw Material (Soft Delete)

```
DELETE /raw-materials/:rawMaterialId
Permission: raw-materials.delete
```

Soft-deletes the record — sets `deletedAt` timestamp and `isActive = false`. The record is **not** permanently removed.

#### Path Parameter

| Param | Type | Notes |
|---|---|---|
| `rawMaterialId` | `uuid` | ID of the raw material to delete |

#### Response `200 OK`

```json
{
  "message": "Raw material deleted successfully"
}
```

---

### 7. Toggle Active Status

```
PATCH /raw-materials/:rawMaterialId/toggle-active
Permission: raw-materials.update
```

Flips `isActive` between `true` and `false`. No request body needed.

#### Path Parameter

| Param | Type | Notes |
|---|---|---|
| `rawMaterialId` | `uuid` | ID of the raw material |

#### Response `200 OK`

Full updated raw material object (same shape as create response). Check `isActive` field to know the new state.

## Raw Material Batches API

### 1. Bulk Create Batches from GRN

```
POST /raw-material-batches/bulk
Permission: stock.create
```

Creates one or more batches from a single GRN. Each batch is tied to a specific GRN line item and storage site. The backend auto-generates a unique `batchNumber` per batch.

**Business Rules (enforced by backend):**
- Each `grnItemId` must belong to the specified `grnId`
- Each `rawMaterialId` must match the raw material on that GRN line
- Total batched quantity per GRN item must not exceed `receivedQuantity` on that GRN line (cumulative across all batch-creation calls)
- Creating batches increments `currentStock` on the associated raw material

#### Request Body

```json
{
  "grnId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "batches": [
    {
      "grnItemId": "f1e2d3c4-b5a6-7890-abcd-ef1234567890",
      "rawMaterialId": "b3f9c1a2-4e2d-4a1b-9c3e-1a2b3c4d5e6f",
      "siteId": "c4d5e6f7-a8b9-0123-cdef-456789012345",
      "quantity": 500,
      "expiryDate": "2026-12-31T00:00:00Z",
      "manufacturingDate": "2026-01-15T00:00:00Z",
      "unitCost": 150.00,
      "notes": "Cold storage lot A"
    },
    {
      "grnItemId": "f1e2d3c4-b5a6-7890-abcd-ef1234567890",
      "rawMaterialId": "b3f9c1a2-4e2d-4a1b-9c3e-1a2b3c4d5e6f",
      "siteId": "d5e6f7a8-b9c0-1234-def0-567890123456",
      "quantity": 200,
      "notes": "Overflow to secondary site"
    }
  ]
}
```

| Field | Type | Required | Notes |
|---|---|---|---|
| `grnId` | `uuid` | Yes | The GRN this batch comes from |
| `batches` | `BatchItemDto[]` | Yes | Min 1 item |
| `batches[].grnItemId` | `uuid` | Yes | GRN line item ID |
| `batches[].rawMaterialId` | `uuid` | Yes | Must match the raw material on that GRN line |
| `batches[].siteId` | `uuid` | Yes | Storage site (warehouse/location) ID |
| `batches[].quantity` | `number` | Yes | Must be > 0 |
| `batches[].expiryDate` | `ISO 8601 string` | No | If omitted, falls back to expiry date on the GRN item |
| `batches[].manufacturingDate` | `ISO 8601 string` | No | |
| `batches[].unitCost` | `number` | No | Must be ≥ 0. If omitted, falls back to unit cost on the GRN item |
| `batches[].notes` | `string` | No | |

#### Response `201 Created`

### 4. FIFO/FEFO Allocation

```
GET /raw-material-batches/fifo/:rawMaterialId?quantity=500
Permission: stock.read
```

Returns batches in FEFO order (First-Expired-First-Out, falling back to FIFO). Only includes `ACTIVE` and `PARTIAL` batches with `availableQuantity > 0` and non-expired `expiryDate`.

#### Path Parameter

| Param | Type | Notes |
|---|---|---|
| `rawMaterialId` | `uuid` | Raw material to allocate |

#### Query Parameter

| Param | Type | Notes |
|---|---|---|
| `quantity` | `number` | Optional. If omitted, returns available batches summary only |

#### Response — Without `quantity` `200 OK`

```json
{
  "rawMaterialId": "b3f9c1a2-4e2d-4a1b-9c3e-1a2b3c4d5e6f",
  "totalAvailable": 950,
  "batches": [
    {
      "id": "11111111-1111-1111-1111-111111111111",
      "batchNumber": "RM-202606-0001",
      "availableQuantity": 450,
      "expiryDate": "2026-06-20T00:00:00.000Z",
      "receivedDate": "2026-06-04T00:00:00.000Z",
      "status": "PARTIAL",
      "site": { "id": "...", "name": "Main Warehouse", "code": "WH-MAIN" },
      "rawMaterial": { "id": "...", "name": "Cotton Yarn", "code": "CTN-YARN" }
    }
  ]
}
```

#### Response — With `quantity=500` `200 OK`

```json
{
  "rawMaterialId": "b3f9c1a2-4e2d-4a1b-9c3e-1a2b3c4d5e6f",
  "requestedQuantity": 500,
  "totalAvailable": 950,
  "totalAllocated": 500,
  "shortfall": 0,
  "isFulfilled": true,
  "allocations": [
    {
      "batchId": "11111111-1111-1111-1111-111111111111",
      "batchNumber": "RM-202606-0001",
      "expiryDate": "2026-06-20T00:00:00.000Z",
      "receivedDate": "2026-06-04T00:00:00.000Z",
      "totalAvailableQty": 450,
      "allocateQty": 450,
      "site": { "id": "...", "name": "Main Warehouse", "code": "WH-MAIN" }
    },
    {
      "batchId": "22222222-2222-2222-2222-222222222222",
      "batchNumber": "RM-202606-0002",
      "expiryDate": "2026-12-31T00:00:00.000Z",
      "receivedDate": "2026-06-04T00:00:00.000Z",
      "totalAvailableQty": 500,
      "allocateQty": 50,
      "site": { "id": "...", "name": "Secondary Warehouse", "code": "WH-SEC" }
    }
  ]
}
```

| Response Field | Description |
|---|---|
| `totalAvailable` | Total quantity available across all valid batches |
| `totalAllocated` | How much of the requested quantity can be fulfilled |
| `shortfall` | How much is missing if demand exceeds supply (0 when fulfilled) |
| `isFulfilled` | `true` if `totalAvailable >= requestedQuantity` |
| `allocations[].totalAvailableQty` | How much was available in that batch before allocation |
| `allocations[].allocateQty` | How much to take from that batch to meet the request |

### 8. Consume from Batch

```
POST /raw-material-batches/:batchId/consume
Permission: stock.update
```

Deducts a quantity from a batch. Automatically:
- Decrements `availableQuantity` on the batch
- Increments `consumedQuantity` on the batch
- Updates batch status to `PARTIAL` (if stock remains) or `CONSUMED` (if depleted)
- Decrements `currentStock` on the raw material master
- Creates a `RawMaterialBatchConsumption` record for audit trail

**Can only consume from `ACTIVE` or `PARTIAL` batches.**

#### Path Parameter

| Param | Type | Notes |
|---|---|---|
| `batchId` | `uuid` | Batch ID to consume from |

#### Request Body

```json
{
  "quantity": 50,
  "referenceType": "PRODUCTION_ORDER",
  "referenceId": "prod-order-uuid",
  "notes": "Used for production run #42"
}
```

| Field | Type | Required | Notes |
|---|---|---|---|
| `quantity` | `number` | Yes | Must be > 0 and ≤ `availableQuantity` |
| `referenceType` | `string` | No | Freeform type of the triggering document |
| `referenceId` | `uuid` | No | ID of the triggering document |
| `notes` | `string` | No | |

#### Response `200 OK`

Updated batch object:

```json
{
  "id": "11111111-1111-1111-1111-111111111111",
  "batchNumber": "RM-202606-0001",
  "receivedQuantity": 500,
  "consumedQuantity": 150,
  "availableQuantity": 350,
  "status": "PARTIAL",
  "rawMaterial": {
    "id": "...",
    "name": "Cotton Yarn",
    "code": "CTN-YARN"
  },
  "site": {
    "id": "...",
    "name": "Main Warehouse",
    "code": "WH-MAIN"
  }
}
```

#### Validation Errors `400 Bad Request`

```json
{ "message": "Batch RM-202606-0001 cannot be consumed (status: REJECTED)" }
{ "message": "Consume quantity must be greater than 0" }
{ "message": "Cannot consume 600 — only 350 available in batch RM-202606-0001" }
```

## Frontend Implementation Notes

### Stock Level Display

- `currentStock` on a raw material represents total stock across all sites and batches.
- When `currentStock <= reorderLevel`, show a low-stock warning indicator.
- `lastPurchasePrice` is returned as a `string` (Prisma Decimal) — always parse with `parseFloat()` before arithmetic.

### Batch Status Colors (suggested)

| Status | Color |
|---|---|
| `ACTIVE` | Green |
| `PARTIAL` | Amber/Orange |
| `CONSUMED` | Gray |
| `REJECTED` | Red |

### Typical Screen Flows

**Raw Materials List Screen**
- `GET /raw-materials` with pagination, search, `isActive` filter
- Toggle button calls `PATCH /raw-materials/:id/toggle-active`
- Delete button calls `DELETE /raw-materials/:id` (confirm dialog first)

**Raw Material Detail / Edit Screen**
- `GET /raw-materials/:id` to load
- `PATCH /raw-materials/:id` to save
- Tab or section for batches: `GET /raw-material-batches?rawMaterialId=:id`
- FIFO view: `GET /raw-material-batches/fifo/:id?quantity=X`

**Create Batch Screen (post-GRN)**
- Loads GRN details to populate `grnId`, `grnItemId`, `rawMaterialId`
- User selects site(s) and enters quantity split
- Calls `POST /raw-material-batches/bulk`

**Batch Detail Screen**
- `GET /raw-material-batches/:batchId`
- Consumption history: `GET /raw-material-batches/:batchId/consumptions`
- Reject/update: `PATCH /raw-material-batches/:batchId`

**Expiry Alert Dashboard Widget**
- `GET /raw-material-batches/expiring?days=30`

**Consume Modal (e.g., from Production Order)**
- `POST /raw-material-batches/:batchId/consume`
- Or use FIFO endpoint first to determine which batches to consume
